# Imágenes del portafolio

Coloca aquí las imágenes reales con **exactamente estos nombres**. Mientras no
existan, la app muestra un placeholder gris automático con las proporciones
correctas (no verás imágenes rotas).

## Dimensiones recomendadas (según specs)

| Archivo | Uso | Proporción | Tamaño sugerido |
|---|---|---|---|
| `retrato.jpg` | Hero (retrato) | 4:5 | 640×800 |
| `historia.jpg` | "Mi historia" | 4:5 | 480×600 |
| `*-card.jpg` | Tarjeta de proyecto (Home) | 16:9 | 640×360 |
| `*-hero.jpg` | Imagen principal del proyecto (Proceso) | 4:5 | 720×900 |
| `*-01.jpg` … | Miniaturas de galería | 1:1 | 800×800 |

## Archivos referenciados por `src/data/proyectos.js`

**Puente de Acero:** `puente-card.jpg`, `puente-hero.jpg`,
`puente-01.jpg` … `puente-06.jpg`

**Pavimentación y Drenaje:** `pavimento-card.jpg`, `pavimento-hero.jpg`,
`pavimento-01.jpg` … `pavimento-05.jpg`

**Expo Académica:** `expo-card.jpg`, `expo-hero.jpg`,
`expo-01.jpg` … `expo-05.jpg`

> Si cambias nombres o cantidades, actualiza también `src/data/proyectos.js`.
